# Assignment 1: HTML & CSS Basics

Web Technologies 1 (Front End), Astana IT University
Student: Nurlan, group SE-2526

**Live site:** https://nurlan-byte.github.io/wt1-assignment1/

## Description

A set of pages built with plain HTML and CSS. No frameworks and no JavaScript are used.
Every page has a navigation bar with links to all tasks.

| Task | Page | Topic |
|------|------|-------|
| 1 | [`index.html`](index.html) | Personal page with a profile card, lists, image and links |
| 2 | [`task2/index.html`](task2/index.html) | Layout built only with `div`, `float` and `position` |
| 3 | [`exercise1/index.html`](exercise1/index.html) | Tribute page for Nikola Tesla with two Google Fonts |
| 4 | [`task4/index.html`](task4/index.html) | Grades table and feedback form |

## How to run locally

1. Clone the repository: `git clone https://github.com/Nurlan-byte/wt1-assignment1.git`
2. Open `index.html` in a browser, or use the Live Server extension in VS Code.
3. Use the navigation bar to open the other tasks.

## How it is published

GitHub repository → **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
